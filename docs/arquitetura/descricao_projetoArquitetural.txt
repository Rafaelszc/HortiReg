2. DETALHAMENTO DOS COMPONENTES E STACK
--------------------------------------------------------------------------------
1. Front-end (Painel Web):
   - Localização: `frontend/`
   - Tecnologia: React 18, TypeScript, Vite, Axios, Cypress para E2E.
   - Porta: `:8081` (Docker) ou `:5173` (Vite dev proxy).
   - Funcionalidades: Autenticação de administrador, CRUD de produtos com apelidos regionais,
     visualização de pedidos confirmados do dia e relatórios de separação.

2. Back-end (API REST & Webhooks):
   - Localização: `backend/`
   - Tecnologia: Python 3.12+, FastAPI, SQLAlchemy, Pydantic v2, Alembic.
   - Porta: `:8000`.
   - Segurança: Autenticação OAuth2 Password Bearer com tokens JWT e hash Bcrypt.
   - Módulos Principais:
     * `routers/webhook.py`: Recebe notificações da Evolution API, valida tokens e
       garante idempotência pelo ID da mensagem (DA-CONF-I2-01 / RK-02).
     * `services/llm.py` e `services/audio.py`: Comunica com Gemini API para extrair itens,
       quantidades e unidades com base estrita no catálogo cadastrado (DA-CONF-I1-01).
     * `services/expiracao.py`: Gerencia a expiração automática de pedidos não confirmados (US-10).

3. Banco de Dados:
   - PostgreSQL 16 na porta `:5432`.
   - Tabelas: `usuarios`, `produtos`, `pedidos`, `itens_pedido`, `mensagens`.
   - Regra estrita de persistência: chave única por `message_id` para evitar pedidos duplicados.

4. Mensageria WhatsApp:
   - Evolution API (Baileys) na porta `:8080`.
   - Envia e recebe mensagens via Webhook assíncrono.

5. Infraestrutura e CI/CD:
   - Orquestração local completa via `docker-compose.yml`.
   - Pipeline GitHub Actions executando linter (`ruff`), segurança (`bandit`, `pip-audit`, `gitleaks`),
     testes unitários e de integração (`pytest`, `pytest-cov` com fail-under de 80%) e E2E (`Cypress`).
