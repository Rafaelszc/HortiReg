                    PROJETO ARQUITETURAL - HORTIREG
================================================================================
Projeto: HortiReg · Gerência de Projetos (UEPB, 2026.2)
Referência visual: docs/arquitetura/hortireg_projetoArquitetural.png

--------------------------------------------------------------------------------
1. VISÃO GERAL DA STACK TECNOLÓGICA
--------------------------------------------------------------------------------
- Front-end:
  * React + TypeScript com build Vite (localizado em frontend/)
  * Interface administrativa para catálogo, produtos e pedidos
  * Estilização moderna e consumo de API REST via Axios/Fetch

- Back-end:
  * Python 3.12+ com framework FastAPI (localizado em backend/)
  * Arquitetura em camadas: Routers, Schemas (Pydantic), Models (SQLAlchemy), Services
  * Autenticação e Autorização via JWT (OAuth2 Password Bearer) e hash Bcrypt
  * Processamento de Mensagens e Áudio com Google Gemini API e Evolution API (WhatsApp)

- Banco de Dados:
  * PostgreSQL 16 (persolvência relacional para usuários, produtos, pedidos e itens)

- Infraestrutura e Automação:
  * Docker e Docker Compose (orquestração dos contêineres: backend, frontend, banco e Evolution)
  * CI/CD via GitHub Actions (execução de linters, pytest e cypress a cada push e PR)

--------------------------------------------------------------------------------
2. FLUXO E INTEGRAÇÕES PRINCIPAIS
--------------------------------------------------------------------------------
1) Canal Web (Painel Administrativo):
   Navegador (React) -> Requisições REST HTTPS -> FastAPI -> PostgreSQL.
   O token JWT identifica o perfil de acesso e os middlewares liberam ou bloqueiam as rotas.

2) Canal WhatsApp (Clientes / Produtores):
   WhatsApp -> Webhook Evolution API -> Endpoint FastAPI (`/webhook`) ->
   Serviço de Áudio / Texto (Gemini LLM) -> Reconhecimento de Intenção e Produtos ->
   Persistência no PostgreSQL -> Notificação / Resposta Automática via WhatsApp.
