3. COMO EXECUTAR A SUÍTE DE TESTES LOCALMENTE
--------------------------------------------------------------------------------
1. Testes Unitários e BDD da API (FastAPI):
   ```bash
   cd backend
   pytest -v --cov=app --cov-report=term-missing
   # Executar apenas testes de fumaça: pytest -m smoke
   # Executar apenas regressão: pytest -m regressao
   ```

2. Testes End-to-End do Painel (Cypress):
   ```bash
   cd frontend
   npx cypress run --spec "cypress/e2e/*.feature"
   ```
